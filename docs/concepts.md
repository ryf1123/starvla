# 概念速查：这个项目里每个设计决策是什么、为什么、在哪、出自哪

读法：先看"一句话"，不懂再看"为什么这样"，想改就看"在哪 / 怎么改"。
每一条都对应 `docs/figs/` 里至少一张图。

## VLA 是什么

**一句话**：一个把「图像 + 自然语言指令」直接映射成「机器人动作」的策略网络。

传统机器人栈是感知 → 规划 → 控制三段分开；VLA 把它们压成一个端到端函数
`π(动作 | 图像, 指令, 本体状态)`，用人类演示数据训出来。
代表工作：RT-1（2022，离散动作 token）、RT-2（2023，把 VLM 直接当骨干）、
OpenVLA（2024，开源 7B）、ACT（2023，动作分块）、Diffusion Policy（2023，扩散动作头）、π0（2024，流匹配）。

本项目做的是**最小可闭环版本**：1.3 M 参数、单任务族、仿真里跑，
但每一块（视觉编码、语言条件化、动作表示、闭环评测）都和大模型版本同构。

## 观测与动作

### 末端增量动作（end-effector delta action）

**一句话**：策略输出「末端往哪挪一小步 + 夹爪开还是合」，而不是 7 个关节角。

**为什么这样**：末端增量和相机看到的东西在同一个坐标系里——画面上「往左一点」直接对应 `dy`。
关节角要网络自己再学一遍逆运动学，同样的数据量下学不出来。
几乎所有 VLA（RT-1/2、OpenVLA、π0）用的都是末端位姿增量 + 夹爪。

**代价**：需要 IK，而 IK 在奇异位形附近会失败。`info["ik_pos_err"] > 5 mm` 就是报警。

**在哪**：`sim/tabletop_env.py` 的 `step()`；尺度 `ACT_POS=0.04 m`、`ACT_YAW=0.30 rad`。
**图**：`env_action_chain.png`（一步的全部数字）、`env_action_scale.gif`（改尺度会怎样）。

### 为什么是 20 Hz

物理跑 500 Hz，策略跑 20 Hz（decimation 25）。
太低（5 Hz）：一步跨过抓取点；太高（50 Hz）：同样时长的演示数据翻 2.5 倍，而相邻帧几乎一样，信息没增加。
真实机器人上的 VLA 普遍在 5–50 Hz 这个区间。

### 两路相机

前视看全局（盘子在哪、有几个方块），腕视看局部（最后 2 cm 对没对准）。
**腕部相机对抓取成功率的贡献通常比前视大**——消融套件 `--suite cams` 就是量这个的。

## 视觉

### 空间 softmax（spatial softmax）

**一句话**：把卷积特征图的每个通道当成「这个通道认为目标在哪」的概率分布，输出它的期望坐标 (x̄, ȳ)。

```
p = softmax(feat.reshape(C, H*W))          # 每个通道一张概率图
x̄ = Σ p · x_grid,  ȳ = Σ p · y_grid        # 期望坐标
```

**为什么这样**：操作任务里策略真正需要的是「东西在哪」。直接 flatten 特征图，
网络要从一堆激活值里自己再学一遍定位；空间 softmax 把这一步白送给它，
而且输出维度从 128×8×8=8192 降到 128×2=256。出自 Levine 等人 2016 的端到端视觉运动策略。

**在哪**：`policy/model.py: SpatialSoftmax`。**图**：`policy_keypoints.png`（关键点画回原图）。

### 为什么不能做色彩增强

任务是**颜色条件**的：指令说「红色方块」，图像里唯一区分目标和干扰物的信号就是颜色。
色相抖动等于把标签擦掉。这里只做随机平移（±4 px，边缘复制补边）。

一般视觉任务里 ColorJitter 是标配——这条是"照搬 CV 经验会翻车"的典型例子。

## 语言

### 为什么语言必须"有序"

指令「把**红色**方块放进**黄色**盘子」里，两个颜色词的**顺序**决定了谁是被抓的、谁是目标。
字符级词袋（把字符嵌入求平均）对这两句话给出**完全相同**的向量——因为它们的字符集一模一样。

更隐蔽的是：**加了位置编码的 Transformer + 均值池化，训完之后也会退化成词袋**。
本项目实测（`notes/03-语言.md`）：训好的 `seq` 模式下
‖z(红→黄) − z(黄→红)‖ = 0.046，而换一组颜色是 2.72。

**修复**：用可学的 [CLS] token 读出（而不是均值池化），位置编码初始化放大到 0.2 → `lang_mode=cls`。

**在哪**：`policy/model.py: LanguageEncoder`。**图**：`policy_lang.png`（四句指令的相似度矩阵）。

### FiLM 条件化

**一句话**：语言向量生成每个视觉通道的缩放 γ 和平移 β，作用在 CNN 中间层的特征图上：
`h ← h · (1 + γ) + β`。

**为什么这样**：让「该看红色还是绿色」这件事发生在**视觉特征里**，而不是等到最后拼接时才补救。
出自 FiLM（2018），RT-1 用的是同一个思路。消融组 `film=false` 就是拿掉它。

## 动作表示

### 动作分块（action chunking）

**一句话**：每一步预测未来 H=8 步的动作，而不是只预测下一步。

**为什么这样**：
1. **复合误差**：逐步预测时，策略每步的小误差把状态推离演示分布，下一步误差更大。预测一整块相当于把决策频率降到 1/H，误差累积的机会少 H 倍。
2. **多步承诺**：「闭合夹爪」是一个需要坚持若干步的决定，单步策略容易在半路反悔来回抖。

出自 ACT（Zhao et al. 2023）。**图**：`policy_chunk.png`。

### 时间集成（temporal ensembling）

第 t 步可以用第 t、t−1、…、t−k+1 各自预测出的、都指向 t 的那一项动作，做指数加权平均。
好处是动作连续、抖动小；坏处是对突变（该果断闭合夹爪了）响应变慢，所以 k 不宜大（默认 4）。

**在哪**：`policy/eval.py: Runner`。`--ensemble 1` 关掉它。

### 三条主流路线（第四环要比的）

| 路线 | 输出 | 代表 | 优点 / 代价 |
|---|---|---|---|
| 连续回归 + 分块 | 直接回归 (H,5)，L1 损失 | ACT | 简单快；对多峰行为会取平均 |
| 离散 token 自回归 | 每维离散成 256 个 bin，交叉熵 | RT-1 / RT-2 / OpenVLA | 能接语言模型骨干；推理要逐 token 解码 |
| 条件扩散 | 从噪声去噪出动作序列 | Diffusion Policy / π0 | 天然处理多峰；推理要跑多步去噪 |

## 训练与评测

### 行为克隆（BC）与它的根本问题

监督学习：`min E[‖π(obs) − 专家动作‖]`。问题在于训练时的状态分布来自专家，
而闭环时的状态分布来自策略自己——**这两个分布不一样，而且会越跑越远**。
缓解手段：给专家加噪声（数据覆盖更宽）、动作分块（少犯错）、DAgger（用策略访问的状态重新标注）。

### 为什么 val loss 不是指标

L1 低只说明「在专家访问过的状态上，预测的动作像专家」。
它不告诉你**策略自己走出来的状态上会发生什么**。
所以每次消融都必须跑 ≥ 50 局闭环，只信成功率。

### 失败要分类

只看成功率不知道错在哪。本项目分三类：

| 归因 | 判据 | 说明什么 |
|---|---|---|
| `wrong_cube` | 动了别的方块，目标方块没动 | 语言没接上 |
| `no_grasp` | 目标方块基本没动 | 定位或抓取失败 |
| `off_plate` | 目标动了但没进盘子 | 放置精度不够 |

**在哪**：`policy/eval.py: classify()`。

## 这台机器上的工程细节

| 坑 | 症状 | 解法 |
|---|---|---|
| 图像用 float32 送 MPS | 训练慢 2.7 倍 | 数据集返回 uint8，`.float()/255` 放到设备上做 |
| `nn.TransformerEncoder` 在 eval() 下 | 训练正常，一验证就 `NotImplementedError` | `enable_nested_tensor=False`（MPS 没实现 nested tensor 快路径） |
| DataLoader `num_workers>0` | 1.8 GB 数据集被复制多份 | 数据不是瓶颈，直接 `workers=0` |
| macOS 上 fork + MuJoCo 渲染 | 子进程崩溃 | `mp.set_start_method("spawn")`，worker 内再 import |

## 阅读顺序

1. **ACT**（Zhao 2023）——动作分块、时间集成，本项目动作头的直接来源
2. **RT-1**（Brohan 2022）——离散动作 token、FiLM 条件化，VLA 的模板
3. **Diffusion Policy**（Chi 2023）——多峰动作分布
4. **RT-2 / OpenVLA**——把预训练 VLM 当骨干，第五环要对照的
5. **π0**（Black 2024）——流匹配动作头 + VLM 骨干，目前的工业级形态
6. **DAgger**（Ross 2011）——为什么 BC 会崩，怎么修

## 和本项目的对照（我加的一节）

| 文献结论 | 我们的实测 | 一致？ |
|---|---|---|
| VLA 对指令改述极其脆弱，很多"语言条件化"只是记住了固定字符串（LIBERO-Para 2026） | 字符级编码器换措辞 **0%**，抓错方块 13/25 | ✅ 完全一致 |
| 用改述指令测策略，掉了说明语言分支实际是死的（该综述明确推荐的诊断） | 我们独立做了同一个诊断，并据此换了预训练编码器（0% → 76%） | ✅ |
| 冻结预训练语言/视觉部分比微调好（GR00T N1.5：语言跟随率 46.6% → 93.3%） | 我们用的就是**冻结** bge-small-zh，收益显著 | ✅ |
| 去掉 FiLM 换成最后拼接，性能掉 5–10%（RoboAgent）/ 9%（MoE-ACT 2026） | 我们掉了 **67 个百分点**（72.5% → 5%） | ⚠️ 方向一致但幅度大得多——因为我们的任务是**纯语言条件**的（三个方块只有指令能区分），而那些工作的任务里视觉本身就能猜个八九不离十 |
| 动作分块把复合误差从 Ω(2^H·ε) 降到 O((k+1)^(H/k)·ε)（2026 理论工作） | 我们一开始就用了 H=8 | ✅ |
| ACT 的 temporal ensembling 是标准配方 | 我们实测**单调有害**（k=1 84% → k=8 65%） | ❌ 冲突。文献没有讨论它什么时候会反号；我们的解释是「20 Hz 确定性回归策略本来就不抖，而抓取需要果断」 |
| spatial softmax + random crop 是 robomimic 验证过的小 CNN 默认配置 | 我们两个都有；但我擅自把 softmax 的温度从 1.0 改成 0.1 并去掉 ReLU，结果掉 15 个百分点 | ✅（教训是别动默认值） |
| 小 VLA 的失败模式是"不知道该看哪里"（2026） | 我们的失败构成里"没抓起来/没进盘子"占绝大多数，正是定位精度问题 | ✅ |
| 评测严重欠功效：13 篇真机 VLA 论文众数 N=10–20，**没有一篇报告置信区间或配对检验** | 我们从一开始就报 95% Wilson 区间，并量化了混沌翻转率（5%） | ✅ 但我们的 n=40 仍然不够（PhAIL 说 ±5pp 需要约 380 次） |
| **数据多样性 ≫ 演示数量**：32 环境 × 每环境 50 条 → 新环境新物体 90% | 我们是**一个固定场景**刷了 800 条演示 | ❌ 这是本项目当前最大的方法缺口 |
| **相机位姿是最难泛化的因素**（真机 91.7% → 45.8%），而仿真里随机化它零成本 | 我们的相机完全固定 | ❌ 同上 |
| 多步历史观测 + 连续动作 + 独立 policy head = 最佳配置（RoboVLMs 600+ 组实验） | 我们是**单帧**观测 | ❌ 可以马上试 |
| 没有 LM backbone 就别把动作离散成 token | 我们实现了离散头但还没跑 | ⚠️ 按此建议应降低优先级 |

**由此得出的三件事**（和调研作者的"如果只能做三件事"高度一致）：
1. **把评测做扎实**——加大局数、配对 McNemar 检验、多训练种子。仿真里 rollout 几乎免费，这是我们相对整个领域的结构性优势。
2. **加多步历史观测**——尺寸无关、成本极低、有 600 组实验支撑。
3. **把"一个场景 800 条演示"换成"几十个随机化场景各几十条"**，尤其要随机化**相机位姿**。

## 0. 一句话总览

到 2026 年，VLA 的主线已经从"能不能做"变成"数据引擎 + 评测协议"的竞争；架构上收敛到 **VLM backbone + 动作专家（action expert）+ 动作分块**，动作表示出现了"离散 token 预训练 → 连续 flow/diffusion 后训练"的两段式共识，以及 2026 年新起的**离散扩散**路线。对小规模复现者来说，真正可迁移的收益不在"更大的 backbone"，而在**动作分块、随机裁剪增强、场景/物体多样性、以及一个统计上站得住的评测协议**。

ICLR 2026 的 164 篇 VLA 投稿综述的判断：LIBERO 已"基本被解决"（95–98%），CALVIN 接近饱和，SIMPLER 跨设置差异 40–99% 难以解读；开源模型在仿真 benchmark 上追平闭源，但**零样本真实任务上仍显著落后**。
https://mbreuss.github.io/blog_post_iclr_26_vla.html

## 1. 主线模型的演化路径

`离散动作 token（RT-1/RT-2/OpenVLA）` → `连续动作专家 + flow matching（π0、GR00T）` → `两段式：离散 token 预训练 + flow matching 后训练（π0.5）` → `加入真实经验/RL 自改进（π*0.6）` → `单模型跨本体 + 组合泛化（π0.7、Gemini Robotics 2）`。**参数量军备竞赛在 2025 年后被"数据多样性 + 后训练方法"取代。**

- **RT-1**（2022）35M 参数 + FiLM 语言注入，证明小模型可行 https://arxiv.org/abs/2212.06817
- **Octo**（2024）27M/93M Transformer + 扩散头，和本项目同数量级 https://arxiv.org/abs/2405.12213
- **OpenVLA**（2024）7B，SigLIP + DINOv2 双编码器 https://arxiv.org/abs/2406.09246
- **π0**（2024）PaliGemma-3B + flow matching 动作专家 https://www.pi.website/
- **π0.5**（2025）两段式；训练环境从 3 个家庭扩到 104 个，性能持续提升 https://arxiv.org/pdf/2504.16054
- **GR00T N1.5**（2025）把 VLM **冻结**，真机语言跟随率 46.6% → 93.3% https://learnopencv.com/gr00t-n1_5-explained/
- **SmolVLA**（2025）450M，只用 487 个社区数据集 10M 帧，超过 ACT 和更大的 VLA；**能在 MacBook 上训练** https://arxiv.org/pdf/2504.05299
- **π*0.6 + RECAP**（2025）不是新架构而是后训练配方：演示 + 专家纠正 + 自主试错 RL https://arxiv.org/html/2511.14759
- **π0.7**（2026）单个 7B 模型控制 7 种本体，零样本泛化 47.3% https://arxiv.org/abs/2604.15483
- **GR00T N2**（2026）world action model 架构（仅有厂商声明，无技术论文）
- 趋势：**"VLA" 正在被 "World Action Model" 挤压**——在动作模型里显式加入世界模型/未来预测

## 2. 动作表示：五条路线

**给小项目的直接答案**：动作分块 + L1 回归性价比最高；离散 token 是为了复用 LM backbone 才付出的代价，没有 LM backbone 就别付；扩散/flow matching 只有在演示明显多模态时才值。

| 表示 | 多模态 | 精度 | 推理开销 | 需要 LM backbone | 小项目适用 |
|---|---|---|---|---|---|
| 均匀分 bin 离散 token | 好 | 差（量化损失） | 高（自回归） | 是 | ✗ |
| FAST（频域离散） | 好 | 好 | 中 | 是 | ✗ |
| 分块 + L1 回归 | 差（收敛到中位轨迹） | 好 | **极低** | 否 | ✓✓✓ |
| 扩散 | 好 | 好 | 高 | 否 | △ |
| Flow matching | 好 | 好 | 中低 | 否 | ✓ |
| 离散扩散（2026 新） | 好 | 好 | 中（并行） | 是 | ✗ |

关键论文：
- **动作分块为什么有效**（2026 理论工作）：非马尔可夫表达力 + 复合误差从 Ω(2^H·ε) 降到 O((k+1)^(H/k)·ε) + 隐式集成 https://www.alphaxiv.org/abs/2608.02547
- **OpenVLA-OFT**（2025）：并行解码 + 动作分块 + 连续动作 + L1 回归 → 推理快 25–50 倍、成功率 +20pp。反直觉发现：**L1 目标会收敛到中位轨迹，从而过滤演示噪声** https://arxiv.org/pdf/2502.19645
- **FAST**（2025）频域动作 tokenization，解决朴素分 bin 在高频任务上失效 https://arxiv.org/abs/2501.09747
- **离散扩散 VLA**（2026 ICLR 最明确的新方向，4 篇并发） https://arxiv.org/html/2508.20072v4

## 3. 视觉编码器

**结论是分场景的，而且对小数据不利于大预训练模型。**

- **《Decomposing the Generalization Gap》**（ICRA 2024）——回答这个问题最直接的论文：
  - 泛化难度**从易到难**：背景 < 干扰物/光照 < 物体纹理 < 桌面纹理/位置 < **相机位姿**。真机换相机位姿 91.7% → **45.8%**；换背景几乎无影响。
  - **随机裁剪意外地全面有效**，不仅改善相机位姿和纹理泛化，还改善干扰物这类非空间因素。
  - **R3M / CLIP 表现令人失望**，跨环境泛化差；**域外机器人演示数据 > 非机器人视觉预训练**。
  - https://arxiv.org/abs/2307.03659 · 代码 https://github.com/RLAgent/factor-world
- **robomimic**（2021）系统化了 **spatial softmax + 随机裁剪 + 观测历史** 这套小 CNN 默认组合，并强调 **checkpoint 选择**导致的巨大方差 https://arxiv.org/abs/2108.03298
- **DINOv2 与 SigLIP 互补**：前者空间精确但无语言接口，后者语义对齐但空间细粒度弱——OpenVLA 干脆两个都用
- 判断：在 1.3M 参数、单场景任务上，**换 DINOv2/SigLIP 不会是瓶颈**（它们比整个策略大 50–500 倍）

## 4. 语言条件化

**按模型规模分层**：小模型用 FiLM，中等用 cross-attention，大模型才直接喂 LM backbone。

- **FiLM（RT-1）**：语言经句子编码器 → **初始化为恒等映射的 FiLM 层** → 注入图像 tokenizer 早期层。恒等初始化是关键
- 去掉 FiLM 换 concat：性能掉 **5–10%**（RoboAgent 2023）/ **9%**（MoE-ACT 2026）
- FiLM vs cross-attention：短上下文下差别不大；**cross-attention 只在"低数据 + 长上下文"时占优**（2026）
- **冻结 VLM 反而更好**：GR00T N1.5 语言跟随率 46.6% → 93.3%，说明**联合微调会破坏预训练的语言接地能力**
- **2026 的两个警告**：
  - **LIBERO-Para**：VLA 对指令改述极其脆弱，很多"语言条件化"其实只是记住了固定字符串 https://arxiv.org/html/2603.28301v1
  - **When Vision Overrides Language**：视觉与语言冲突时，VLA 往往忽略语言 https://arxiv.org/pdf/2602.17659

## 5. 数据与泛化（最重要的一节）

**环境和物体的多样性远比演示数量重要，而且泛化性能对多样性呈幂律，对"每个环境的演示数"很快饱和。**

- **Data Scaling Laws**（ICLR 2025，40k 演示 / 15k 真机 rollout）：
  - 泛化与**环境数**和**物体数**呈近似**幂律**
  - **32 个环境 × 每个 1 个独特物体 × 每个 50 条演示 → 对全新环境和全新物体 90% 成功率**
  - https://arxiv.org/abs/2410.18647
- **DROID**（2024）：与 DROID 共训比与 Open-X 共训更好（分布内 +22pp，分布外 +17pp）→ **"野外多样性" > "把很多实验室数据集堆在一起"** https://arxiv.org/pdf/2403.12945
- **数据增强**：
  - 有用：**随机裁剪**（最全面）、色彩抖动（仅纹理类）
  - **有害**：random color cutout（可能遮住夹爪或目标）
  - **用增强 + 50% 数据 > 不用增强 + 100% 数据** https://arxiv.org/html/2511.09932
- **OXE 的数据质量有问题**：ICLR 2026 综述指出其"大量包含低质量演示"，2026 出现了一批演示筛选工作

## 6. 评测方法学：文献里最"扎心"的一节

**当前 VLA 领域的评测在统计上严重欠功效，这是 2026 年被正式量化和批判的问题。**

**PhAIL**（2026）https://arxiv.org/html/2605.29710
- 调查 13 篇 2023–2025 真机 VLA 论文：**每条件众数 N = 10–20**，**没有一篇报告置信区间或配对检验**
- 想要 ±5 个百分点的 95% Wilson 区间，单臂需要约 **380 次 rollout**
- 配对二元比较（分层 McNemar）**每个 cell 需要 600–1500 次**
- 他们提出的"到成功时间 CDF 的宏平均 KS 检验"只需每 cell **25–45 次**
- 原话：*"The field's modal N≤25 is therefore an order of magnitude or more below the per-cell binary-test budget at our effect size."*

其他批评：
- **LIBERO-PRO**（2025）：用官方 OpenVLA 权重复现 LIBERO-Object，成功率比论文报告**低 19 个百分点**；在 LIBERO-plus 上不重训直接测**暴跌到 23.4%** https://arxiv.org/html/2510.03827v1
- **checkpoint 选择的作弊风险**："每 1k step 评一次、报最好的" 会系统性抬高性能
- **聚合指标掩盖结构**：平均 70% 可能是"一致地平庸"，也可能是"80 个优秀 + 20 个完全失败"

## 7. 小规模复现

**仿真 benchmark**：LIBERO（已基本被解决）、RoboCasa（厨房场景多样性）、SIMPLER（真机相关性 r>0.8 但不支持腕部相机）、**VLABench**（模块化任务生成，最贴合"程序化生成多样场景"）、**factor-world**（19 任务 × 11 变化因子的受控泛化 benchmark）。

**小模型能到什么程度**：
- RT-1 只有 35M 参数就做出真机多任务泛化
- SmolVLA 450M **能在 MacBook 上训练**，超过 ACT
- TinyVLA（2024）1B backbone 消费级 GPU 上 50Hz，**不需要预训练阶段**
- **反面警告**：《Teaching Tiny VLA Models Where to Look》（2026）——把 VLA 做小会移除操作必需的能力，**尤其是"知道该看哪里"**：小 VLM 能识别物体，但无法足够精确地定位任务相关的那个实例 https://arxiv.org/html/2607.04171v3
  - 推论：**spatial softmax 存在的理由正是这个**——把特征图显式转成 2D 关键点坐标，直接提供"看哪里"，而不指望网络从全局池化特征里恢复

**RoboVLMs / 《What matters in building VLA models》**（2024 → Nature MI 2026）：8+ 个 backbone × 4 种策略架构 × **600+ 组受控实验**。核心结论：**多步历史观测作为输入 + 连续动作作为输出 + 用独立 policy head 组织历史** 时性能最好。这三条**全部与模型规模无关**。 https://arxiv.org/abs/2412.14058

## 8. 调研作者的"如果只能做三件事"

1. **先修评测，再改模型** —— ≥200 次/条件、报告 95% bootstrap/Wilson CI、配对同种子 + McNemar、≥3 个训练种子、固定 checkpoint 规则、分条件报告。*"你在 MuJoCo 里 rollout 几乎免费，这是相对整个领域的结构性优势。"*
2. **加动作分块 + 多步历史观测 + 连续动作 + spatial softmax** —— 全部与规模无关，参数增量极小
3. **把训练数据从"多演示"换成"多场景 + 随机化相机位姿 + 随机裁剪"** —— 真机上多样性最贵，仿真里几乎免费

**明确不建议的三件事**：不要换 DINOv2/SigLIP 大编码器；不要为了"像 VLA"把动作离散成 token；不要在 LIBERO 上刷分。

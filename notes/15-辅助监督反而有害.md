# 15 辅助定位监督：−62 个百分点

## 想法

用仿真的特权信息（目标方块和目标盘子在两个相机里的**真实像素坐标**）给视觉分支一个
直接的定位信号，而不是只靠动作损失间接学。诊断显示瓶颈是"闭合夹爪时对不准"
（`notes/12`），这看起来是对症下药。

实现：视觉特征（两路相机的关键点，共 512 维）→ MLP → 预测 10 维特权向量
（前视目标方块 uv + 可见性、腕视目标方块 uv + 可见性、前视目标盘子 uv + 可见性、方块高度）。
总损失 = 动作 L1 + `aux_weight` × MSE。

## 结果：灾难

| | 成功率（80 局，同种子） | 95% 区间 |
|---|---|---|
| 无辅助监督 | **86.2%** | 77%–92% |
| **辅助监督（weight=1.0）** | **23.8%** | 16%–34% |

配对：只有无辅助成功 **53** 局，只有辅助版成功 **3** 局，**McNemar p < 0.001**。

失败构成也变了：`wrong_cube` 从 0 涨到 **17 局**——**语言接地也坏了**。

## 辅助任务本身学得很好

`val_aux_uv_err = 0.0374`（归一化图像坐标），换算到 128×128 上约 **2.4 个像素**，
对应桌面上约 8 mm。**视觉特征里确实含有目标位置信息，而且很准。**

所以不是"学不会定位"，而是**为了学定位，特征被专门化了，控制反而垮了**。

## 可能的机制（推测，未验证）

辅助头吃的是空间 softmax 之后的**关键点坐标**（每个通道一个 (x,y)）。
强迫这 512 维去回归"目标的绝对像素坐标"，最省力的解可能是让一部分通道
直接锁定目标位置——但动作真正需要的是**夹爪相对方块的位置差**，
以及夹爪自身、盘子、其他方块的关系。表示被辅助任务占用之后，这些就挤掉了。

## caveat：只测了 weight=1.0

这个结论只覆盖 `aux_weight=1.0`。更小的权重（0.1、0.01）完全可能是中性甚至正收益——
辅助损失在收敛时只有 0.0075，而动作 L1 是 0.09，**看起来权重 1.0 并不算大**，
所以这个崩塌不是简单的"权重太大压过主任务"，更像是表示层面的冲突。
但严格说，"辅助监督有害"这个结论需要扫一遍权重才能下。

## 教训

这是本项目第三个"看起来一定有用、实测是负收益"的技巧
（前两个是空间 softmax 的"修复"和 ACT 的时间集成）。共同点是：
**它们都在改一个中间表示，而中间表示好不好只能用最终指标判断。**

顺带：这也再次说明代理指标不可靠——辅助任务的误差（2.4 像素）非常漂亮，
如果只看它，会以为视觉分支变强了。
